# 0.3.0-beta.1

Beta gratuita para Windows x64, preparada localmente y todavía sin publicación automática en GitHub

La carrera completa pasa a Godot, con clases narradas, consultas SQLite reales, modelador, cuaderno y Liga de Dioses

Nexo añade publicaciones con alternativas, contactos, recomendaciones y quince encargos, tres proyectos avanzan en cuatro etapas y se pueden exportar con datos y pruebas

La casa empieza con lo básico y permite comprar once artículos o mejoras, las investigaciones, cinco desafíos de bolsillo y el proyecto final dan variedad al recorrido académico

La nueva presentación usa verde profundo, crema, madera y cobre, con fuentes legibles, controles agrupados, ventanas con confirmación de cambios y narración sincronizada con el texto de las clases

Se comprueban las 25 clases, los 64 ejercicios y las 20 preguntas SQL de examen, las recompensas únicas, la recuperación del guardado y la ejecución del paquete extraído

La partida de Godot usa una carpeta independiente, la importación no modifica el progreso de Pygame, conviene conservar los respaldos al probar una beta
