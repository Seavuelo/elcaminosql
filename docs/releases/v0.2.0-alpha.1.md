# El Camino SQL v0.2.0-alpha.1

**Versión experimental, una beta de la beta**

Esta entrega permite probar el proyecto y dar comentarios, todavía está en desarrollo y puede contener errores, detalles visuales pendientes y materia que necesite más claridad

## Cómo jugar en Windows

Descarga `ElCaminoSQL-0.2.0-alpha.1-Windows-x64.zip`, extrae todo su contenido y abre `ElCaminoSQL.exe`, conserva la carpeta `_internal` junto al ejecutable

No requiere instalar Python ni dependencias y funciona sin conexión después de descargarlo

El archivo `Source code` que ofrece GitHub contiene el proyecto para desarrolladores, el ZIP de Windows contiene la versión para jugar

## Qué incluye

- Semana introductoria de cinco días con Marco, Moshi y compañeros, pizarras ilustradas y voz Santa
- Kashut con preguntas, podio, retroalimentación y recompensas
- Carrera de cuatro años con clases, ejercicios SQL reales y pruebas de los viernes
- Editor SQL multilínea, resaltado, catálogo, resultados y pistas graduales
- Modelador lógico y relacional con entidades, atributos, claves y relaciones
- Cuaderno con secciones, búsqueda y apuntes personales
- Personalización del estudiante y animaciones de los compañeros
- Liga de Dioses opcional dentro del teléfono
- Menú, aulas, interfaces e ilustraciones renovadas, con ayuda contextual en F10
- Música por contexto, volumen independiente y voz activable en la introducción
- Confirmación antes de empezar una nueva partida y protección contra aperturas simultáneas

## Límites de esta versión

La voz está preparada solo para la semana introductoria, las otras clases conservan su presentación de texto

Este paquete está preparado en Windows x64 y se comprueba localmente, todavía falta probarlo en otros equipos y durante partidas largas

El juego aún se centra en la universidad, la práctica profesional, el mundo laboral y las recomendaciones entre contactos quedan para futuras versiones

## Guardado y comentarios

El progreso se guarda en `%USERPROFILE%\.config\sql-quest\`, actualizar el paquete no lo elimina, conviene conservar una copia antes de probar versiones experimentales futuras

Reporta problemas en https://github.com/Seavuelo/elcaminosql/issues indicando esta versión, lo que ocurrió y los pasos para repetirlo
