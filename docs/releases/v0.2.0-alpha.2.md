# El Camino SQL v0.2.0-alpha.2

**Versión experimental — Liga de Dioses renovada**

Liga ocupa casi toda la pantalla y tiene una identidad propia, con colores cálidos, marcos, iconos, retratos y botones dedicados

- Nueve dioses originales con habilidades, perfiles y afinidades
- Seis estrategias y seis reliquias con ventajas y desventajas, 324 combinaciones
- Información del próximo rival antes de entrar a la partida
- Arena con carriles, río, bases, torres, oleadas y equipos de cinco
- Relato y marcador basados en los mismos eventos de combate
- Dos o tres jugadas de precisión por partida, con aviso previo y mejoras que amplían sus ventanas hasta 1,3 segundos
- Remates que pueden convertir una cuadra real en penta, objetivos e intercepciones
- Pantalla de resultado con bajas, muertes, asistencias, puntos y precisión
- Teléfono decorado y accesible desde ambas aulas

Las partidas siguen siendo opcionales y no generan XP repetible, cerrar el teléfono permite continuar estudiando, fallar o ignorar un evento no quita XP

Se conservan el progreso y las partidas anteriores, usa esta versión para continuar después de elegir uno de los dioses nuevos, las versiones anteriores no conocen esos dioses

## Para jugar

Extrae todo `ElCaminoSQL-0.2.0-alpha.2-Windows-x64.zip` y abre `ElCaminoSQL.exe`, conserva `_internal` junto al ejecutable, no necesitas instalar Python

F4 abre el teléfono y F10 muestra controles, para las jugadas de precisión puedes apuntar con el ratón o usar Espacio

## Estado

Esta sigue siendo una alpha, el equilibrio de combinaciones y la dificultad de precisión necesitan más partidas humanas y pruebas en otros computadores

Más detalles en `docs/LIGA_DE_DIOSES.md`, comentarios en https://github.com/Seavuelo/elcaminosql/issues
